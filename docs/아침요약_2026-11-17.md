## 2. UI 전면 정리
- 이모지 제거, 선 아이콘(Lucide)과 Pretendard 글꼴로 교체
- 기본 글자 18px → 17px, 카드·버튼·칩 스타일 통일, 다크 모드 유지
- 홈: 서비스 정체성을 '여정 단위 연결 / 출처 표시 / 빈칸은 질문·제보로' 3줄로 설명
- 상세 페이지 순서: 개요 → 여정 체크 → 객실 → 예약·할인 → 주변 시설 → 시설 관리 → 출처
- 소개 페이지: 기존 서비스(열린관광, 숲나들e 등)와의 차이 3가지, 출처 표시 범례, 렌즈(준비 중) 원칙

## 3. 이용자 제보 (P1)
- 빈칸·추가 확인 항목마다 '다녀왔다면 이 빈칸 제보하기' → 있었어요/없었어요/잘 모르겠어요 + 한 줄 메모(120자) + 방문 연월
- 전화번호·이메일·차량번호·주민번호 형태 메모는 거부, 자동등록 방지 필드, IP당 10분 8건 제한
- 신고 3번이면 자동 숨김, 관리자 숨김 API(`ADMIN_TOKEN` 환경변수 필요)
- 제보는 정보 확인도에 넣지 않고 노란색 '이용자 제보'로 따로 표시
- 저장소: Upstash Redis 환경변수가 있으면 Redis, 없으면 로컬은 `.data/reports.json`, 배포 환경은 메모리(시연 모드 문구 표시)

## 4. 온라인 자료 참고 구조
- `src/data/web_checks.json`: 블로그·공지에서 찾은 내용을 직접 요약해서 넣는 파일 (형식은 파일 안 `_comment`, `_example` 참고)
- 주황색 '온라인 후기 참고 / 운영기관 공개자료'로 표시, '미확인' 표기, 항목 상태는 바꾸지 않음
